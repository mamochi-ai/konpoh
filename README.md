# こつこつ梱包室

**LINEスタンプ（通常の静止画）** の制作仕上げ用の日本語Webアプリです。一覧画像の分割・背景透過、**販売前チェック**、**投稿用ZIPの梱包**を端末内だけで行います。
サーバー・ログイン・外部AI APIは使いません。静的ホスティングでそのまま動きます。

- 実装指示とキット：`docs/kit/`（`CLAUDE_CODE_PROMPT.md`、画面見本 `design-reference.png`、テストの期待結果 `TESTS_README.md`）
- チェック条件：`src/templates-builtin/line-static.json`（LINE通常静止画。スタンプ数 8/16/24/32/40 から選択）。BOOTH用テンプレート、組合せセット、テンプレートの作成・編集機能は、LINEスタンプに特化する方針で外しました。
- マスコット：`src/assets/`（キット同梱の透過PNGを320pxに縮小。透過は維持）

## iPadだけで使う（PC不要）

次のリンクをiPadのSafariかClaudeアプリで開くと、そのまま使えます（非公開。開けるのは所有者と共有した人だけ）。

**https://claude.ai/artifact/NnUG4mckozZqu8MoRg14PG**

- 画像やZIPの処理はiPadのブラウザ内だけで行い、どこにも送信しません。
- ZIPやバックアップの保存は、claude.aiの保存確認（Claudeアプリでは共有シート）が出るので「保存」を選びます。
- 端末内保存（「保存」ボタン）はこのページ専用の領域に入ります。消えることがあるので、大事な作品はバックアップZIPも保存してください。
- 中身は `artifact/konpoh.html`（`npm run build:artifact` で作る1ファイル版。画像・JS・CSSを埋め込み済み）。

## 起動手順（PCで開発する場合）

```bash
npm ci            # 依存は package-lock.json で固定（.npmrc で legacy-peer-deps を指定）
npm run dev       # 開発サーバー http://localhost:5173
npm run build     # dist/ に静的ファイルを出力（相対パス。任意の静的ホスティングに置ける）
npm run preview   # dist/ を http://localhost:4173 で確認
```

Web Crypto（SHA-256）を使うため、公開する場合は **HTTPS** で配信してください（localhost は可）。公開デプロイは今回の範囲外です。

## できること（今回の完成範囲）

| 区分 | 内容 |
|---|---|
| 読込 | 「画像を追加」（複数選択）／「ZIPを読み込む」。シグネチャで形式判定（拡張子を信用しない）。GIF/SVG/HEIC/WebP等は変換せず「非対応」と表示。APNGは acTL で検出し対象外。画像以外は取り込まず理由を一覧表示 |
| ZIPの安全策 | アプリ上限 200ファイル／展開100MB／1画像16メガピクセル（販売先の上限とは別）。宣言サイズと**展開中の実バイト**を監視し超過で中止。ネストZIPは展開しない。絶対パス・`..`・正規化後に重複するパスを拒否。暗号化・ZIP64は非対応。1件壊れていても他は継続 |
| 役割 | ファイル名（`01.png`〜、`main.png`、`tab.png`）から役割「候補」を付け、利用者が「候補を確定」。役割変更、前へ／後へ（ドラッグ不要）、出力名の個別変更 |
| 検査 | 寸法（exact/max/none）・形式・容量・偶数寸法・透過（不透明／完全透明／透明画素あり）・DPI（PNG pHYs／JPEG JFIF）・余白（alpha>閾値、閾値は変更可）。セット単位で必要枚数の過不足・未割当・出力パス衝突・完成ZIP容量 |
| 結果表示 | 合格・要確認・エラー・未検査。画像数とルール違反件数を別表示。1枚の複数指摘を全件、実測値・要求値・出典区分（公式条件／アプリの推奨）つきで表示。「要確認だけ」で絞込み。白／黒／市松の背景プレビュー |
| 差替え | assetId・役割・順序を維持したまま差替え、検査結果を破棄して自動で再検査。差替え履歴を表示 |
| 規格 | LINE通常静止画のみ。画面ではスタンプ数（8/16/24/32/40）と余白判定のalpha閾値だけを選べます |
| 梱包 | ZIP内ツリー、ファイル数、元名→出力名、対象/除外、予定サイズ（事前に正確計算）を確認。画像は**無圧縮格納で再エンコードしない**。生成後に再展開してSHA-256一致を検証。進捗・中止・失敗時の再試行 |
| 書出しの制御 | 投稿用：未検査・エラー・容量超過では停止。警告だけなら確認チェック後に可。作業用：別ボタンで、未検査/指摘ありが分かる名前で保存可。読込不能・パス衝突はどちらも解決必須 |
| 保存 | 「保存」でブラウザ内（IndexedDB）に保存（失敗は画面に表示）。素材・役割・順序・設定・検査結果を含むバックアップZIPの保存／復元 |
| 一覧画像の分割 | 透明（または背景色）のすき間から分割線を自動検出、または行×列で等分。線は指でドラッグ、または選んで±1/±10pxのボタンで調整、追加・削除も可。空のマスは自動除外、マスごとに除外も可。余白を詰める・LINE用サイズ調整（スタンプ最大370×320・余白10px・偶数／メイン240×240／タブ96×74、縮小のみ）。選んだ役割（例：スタンプ）へ順に割り当て |
| 背景透過 | 外周から推定した背景色（画像タップや色指定でも可）と許容幅で、外側からつながる部分（または同じ色すべて）を透明に。境目をなめらかにする処理あり。市松/白/黒で確認。AIではないので写真・グラデーション背景や、絵の中の背景と同じ色の部分は苦手 |
| 編集結果の扱い | 元画像は変更せず、結果を**新しい画像（72dpiのPNG）**として追加し「作成元」を記録。透過では元画像の役割を引き継げる。追加後に自動で検査。元画像の書出し・外部で直した画像での差し替えも可 |

### 試し送り（タブ「試し送り」）

架空のトーク画面で、スタンプの文字の読みやすさ・印象・会話での使いやすさを確かめる機能です。**実際のLINEへの送信や接続はしません**（AI API・サーバー・ログインも不要。画像と会話は端末内だけ）。編集やチェックの前でも使え、試すだけで何も書き出さずに終えられます。試し送りをしても販売前チェックの合格にはなりません。

| 区分 | 内容 |
|---|---|
| 画像 | 「プロジェクトの画像から選ぶ」（コピーせず参照。未分割の一覧画像は選べず、分割後の画像は選べる）／「画像を読み込む」（PNG・JPEGを複数。中身で形式を判定し、壊れた画像は理由を表示して他は続行）。元画像は変更しない |
| トーク | 相手のメッセージは左、自分のスタンプは右。タップで一覧から送信（最新が見える位置まで自動スクロール）。スタンプは縦横比・透明部分を保ち、吹き出しや白い背景を付けない。送信済みを選んで削除・メモ・比較の修正前に指定。「最後の送信を取り消す」「会話をリセット」（画像とメモは消えない）。「相手が受け取る」で左右を入れ替えた見え方も確認 |
| お題 | 家族・仕事・友達・待ち合わせ・ねぎらい（各3つ、固定データ）。会話文は吹き出しをタップして編集、相手のメッセージを追加、自作のお題を追加・編集・削除。送信済みがある状態でお題を変えると「会話を残して続ける／新しく始める／やめる」を選ぶ |
| 背景・サイズ | 明るい／暗い／淡い青／好きな色（カラーピッカー）。表示サイズは小さめ／標準／大きめ（表示だけ。画像は変えない）。実際のLINEとは端末や設定で表示が異なる旨を表示 |
| メモ | 画像ごとに「文字が読みにくい」「背景や白縁を調整したい」「表情やポーズを調整したい」「このままでよさそう」と自由記入。**自動チェックの結果とは別欄**。ファイル名ではなく画像IDで管理（同名ファイルでも混ざらない） |
| 修正前後の比較 | 修正前を選び、修正後（外部のアプリやAIで直した画像も可）を読み込んで組にする。同じ会話文・背景・表示枠で、iPadは横並び、狭い画面は前後切り替え。**「修正後をプロジェクトに採用」は別の明示操作**：プロジェクトの画像は差し替え（役割と順序は維持、チェック結果は破棄して「未検査」、再チェックの案内）、修正前は比較用に残す |
| 他の機能へ | 「編集で開く」「チェックで見る」（プロジェクトの画像）、「元画像を書き出す」「修正版を読み込んで比較」「プロジェクトに追加」（試し送りで読み込んだ画像は未検査として追加し、二重に持たない） |
| 保存 | 画像・メモ・自作のお題・表示設定・会話・比較の組を IndexedDB に自動保存（画像はBlobのまま。localStorageは使わない）。保存状態を表示し、失敗したら失敗と表示。ブラウザのデータ削除で消える旨を表示。表示用のObject URLは使い回し、不要になったら解放 |

開き方：上部のタブで「試し送り」を押す → 右の「画像を読み込む」または「プロジェクトの画像から選ぶ」→ 画像をタップして送る。

### 判定の方針（主なもの）

- LINEの容量：1MB＝**1,000,000 bytes**、60MB＝**60,000,000 bytes** として保守的に判定（公式ページが換算を明示していないため。画面にも表示）。
- DPI：pHYs 2835 px/m（=72.009dpi）など、72dpi保存の丸め誤差（±0.1dpi）は許容。pHYsなし・単位なし・EXIFのみは **未確認**（72dpiと補完しない）。未確認があると「全部OK」にしない。
- 透過：透明画素があるだけで「背景処理が正しい」とは判定せず「透明画素あり・見た目の確認は必要」と表示。完全不透明・完全透明（内容なし）はエラー。
- 余白：alpha>8（初期値）の範囲から測るヒューリスティックの**目安**で、要確認（警告）扱い。
- スタンプ370×320は**上限**（一致は強制しない）。main/tabは固定寸法。
- 規格チェックの合格は審査合格や著作権の保証ではない旨を画面に常時表示。
- マスコット：検査前は待機、全画像検査済みかつ指摘ゼロのときだけ検査完了、ZIP生成成功で梱包完了。

### 保存ファイル名について

claude.ai上では、埋め込みページのダウンロードリンクが使えないため、claude.aiの保存機能（`downloads`）を通して保存します。自前で配信した場合は通常のダウンロードになります。確認は画面内のダイアログで行います（`confirm()`は使いません）。


テスト環境のChromiumでは、`download` 属性の**日本語ファイル名が捨てられ「download」（拡張子なし）になる**ことを確認しました。iPad Safariでの挙動を実機確認できないため、保存名は英数字にしています。

| 種類 | 例 |
|---|---|
| 投稿用ZIP | `UPLOAD_line-static.zip` |
| 作業用ZIP | `WORK-unchecked_…` / `WORK-has-issues_…` / `WORK-needs-review_…` / `WORK-checked_…` |
| バックアップ | `BACKUP_konpoh_20261101-1506.zip`（中に `konpoh-backup.json`。投稿用ZIPとは別物） |

ZIPの**中身**は `01.png`〜、`main.png`、`tab.png` をルート直下に置きます。投稿用ZIPにマスコットや説明ファイルは入れません。

## 未確認・残っている制限

- **iPad Safari 実機では未確認です。** 確認できたのはLinux上のChromium（Playwright）だけです。次の項目は実機で確認が必要です：ファイルアプリからの複数選択、ZIPの保存（Blob URLのダウンロード）、縦/横回転、長いファイル名、連続差替え、拡大表示、指だけでの操作、IndexedDBの容量と永続性。
- iPadの「写真」から選んだHEICは、iPadOS側がJPEGに変換して渡すことがあります（アプリ側では変換しません）。
- JPEGのDPIは JFIF のみ対応。EXIFの解像度やICCプロファイルなど未対応のメタデータは「未確認」扱いで、RGBの完全な証明はしていません（グレースケールPNGは警告）。
- アルファ解析はCanvasで行います。ブラウザの色管理の影響はアルファ値には及ばない前提です。
- 保存ファイル名は英数字です（上記の理由）。
- 端末内保存は1作品（最後に保存したもの）を自動で開きます。複数作品の一覧管理はありません（バックアップZIPで管理してください）。
- 読込時のサムネイル作成と検査は1枚ずつ逐次処理です（巨大画像の一斉展開を避けるため）。
- 試し送りの表示はアプリ内の模擬画面で、LINEの実際の表示（サイズ・余白・吹き出し）を再現するものではありません。
- 試し送りは iPhone / iPad の Safari 実機では未確認です（タッチでの送信・スクロール、カラーピッカー、下部の一覧の開閉、IndexedDBの容量）。
- 試し送りで「プロジェクトに採用・追加」した変更は、これまでどおり上部の「保存」で作品を保存してください（試し送り側は自動保存）。
- 背景透過は色の近さによる処理です。写真・グラデーション背景、絵と背景が同じ色で外とつながる部分、重なった絵の分離はできません。
- 分割は縦横の直線のみです（斜め・不規則な形の切り抜き、文字と小物の手動グループ化は未実装）。
- 未実装：文字入り表紙レイアウト、一覧画像の生成、アニメーション・ポップアップ等の他のLINEスタンプ種別。

## 構成

```
src/core/      業務判定（UI非依存の純粋関数）
  edit/          背景透過・分割・縮小・PNG書出し（72dpi）
  sniff.ts       形式判定・PNG/JPEGヘッダー・DPI
  facts.ts       画素からの事実（透明度・余白）とアプリ上限
  rules.ts       テンプレート×事実→指摘、セット評価、書出し可否
  templates.ts   同梱LINEテンプレートとその検証（schemaVersion）
  project.ts     役割割当・並べ替え・差替え
  naming.ts      命名プリセットと出力パス検証
  zip.ts         ZIP読込（上限監視）と無圧縮書出し
  backup.ts      プロジェクトバックアップ
  trial.ts       試し送りのお題・会話・メモ・比較（純粋関数）
  sheet.ts       一覧画像の見分け
src/app/       ブラウザ層（IndexedDB、Canvasデコード、状態管理）
src/ui/        Preact画面
tests/unit/    Vitest
e2e/run.mjs    Playwrightによる実ブラウザ確認
```

依存（固定版）：preact 10.29.8、fflate 0.8.3（ZIPの展開のみ）、vite 7.3.7、vitest 4.1.12、typescript 5.9.3。
