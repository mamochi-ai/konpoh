# こつこつ梱包室：Claude Code実装キット

これは完成アプリではなく、実装指示・素材・テンプレート・テストデータの一式です。

## iPadから渡す方法
1. Kotsukotsu_ClaudeCode_Kit.zipをClaude Codeに添付。
2. 「ZIPを展開し、CLAUDE_CODE_PROMPT.mdを読んで実装してください。まずチェック・自作テンプレート・梱包を完成させてください」と送信。
3. 完成後にtests/valid-line-16.zipを実際に読み込んで確認。

## 内容
- CLAUDE_CODE_PROMPT.md：そのまま渡せる実装指示。
- assets/design-reference.png：承認済みの画面見本。スクリーンショット内の画像と数値は架空例。
- assets/mascot-waiting.png / mascot-checked.png / mascot-packed.png：新規生成の個別透過素材。
- templates：チェックテンプレート2種類と組合せ例。初期スキーマ案で、バリデーションも実装対象。
- tests：正常、サイズ違い/不透明、不足セットと単体異常画像。

## 基本方針
編集・検査・梱包を独立。チェックではファイルを書き換えない。外部AIで編集した結果を差替え可能。サーバー/AI APIなし。利用者はiPadのみ。画像編集機能は第2段階。

## 素材制作
マスコットは組込み画像生成で制作。共通指示：承認済みマーモットの茶色の丸い体、点の目、2本の白い前歯、クリーム色の口元と腹、丸耳を維持。マフラーなし、文字なし、透過、全身。待機＝開いた空箱、検査完了＝青緑チェックのボード、梱包完了＝テープで封をした箱。UIでは小さく表示。
